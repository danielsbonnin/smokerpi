🎯 How It Works

SmokerPi uses a PID (Proportional-Integral-Derivative) controller to maintain precise temperature control in your electric smoker. The system reads the current temperature, compares it to your target, and adjusts the heating element duty cycle accordingly.

Try adjusting the controls above to see how different parameters affect the system:

  • Target Temperature: Your desired cooking temperature (150-350°F)
  • Ambient Temperature: Outside temperature affects heat loss
  • P (Proportional): How aggressively to respond to temperature error
  • I (Integral): Corrects accumulated error over time

The duty cycle shows what percentage of time the heating element is ON vs OFF. The system automatically adjusts this based on the PID calculations and environmental conditions.
